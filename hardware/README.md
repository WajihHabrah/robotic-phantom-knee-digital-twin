# Hardware

This directory contains selected technical documentation related to the physical Robotic Phantom Knee platform.

The hardware architecture includes:

* Antagonistic robotic actuators
* Variable-stiffness mechanism
* Pneumatic soft-tissue subsystem
* Embedded sensing
* Mechanical structure
* 3D-printed components
* Raspberry Pi-based control hardware

Detailed system-level information is available in:

[System Architecture](../docs/system-architecture.md)

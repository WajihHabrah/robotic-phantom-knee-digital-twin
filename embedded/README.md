# Embedded Systems

This directory contains selected documentation and source files related to the distributed embedded sensing subsystem of the Robotic Phantom Knee.

The embedded system includes:

* FeatherS3 microcontroller platforms
* ISM330DHCX inertial measurement units
* MMC5983MA magnetometers
* TMP117 temperature sensors
* Sensor acquisition and communication with the Raspberry Pi

Only files suitable for public release are included in this repository.
